# QA Log Analyzer

## 概要

QA業務でのログ解析を効率化するために開発したWebアプリです。

ログファイルをアップロードすると、ERROR・WARNINGの件数集計やエラー率の算出を行い、異常ログを視覚的に確認できます。

---

## 機能

- ログファイルアップロード
- ERROR件数集計
- WARNING件数集計
- エラー率表示
- ERROR詳細表示
- WARNING詳細表示
- ダッシュボード表示
- カラー表示による可視化

---

## 使用技術

- Python
- Flask
- HTML
- CSS

---

## 開発背景

品質保証(QA)業務ではログ解析を行う機会が多いため、ログの異常を効率的に確認できるツールとして開発しました。
